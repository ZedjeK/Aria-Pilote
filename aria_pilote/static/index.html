                                Sous-agents
                                
                    
                                Des agents spécialisés que l'agent principal lance pour une sous-tâche, avec leurs propres outils.
                                
                    
                                  
                
                                  
            
                                  

            
                                  
                
                                  Commandes PowerShell lancées autour du travail de l'agent, dans tous les projets (hooks.json).
                                  
                
                                  
                    
                    
                                  Événements : avant_outil (code de sortie 2 = action bloquée), apres_outil (sortie ajoutée au résultat),
                        debut_tache (sortie donnée à l'agent), fin_tache. Variables : ARIA_OUTIL, ARIA_ARGS, ARIA_FICHIER, ARIA_STATUT.
                                  
                    
                                  
                    
                                  
                        
                    
                                  
                
                                  
            
                                  
            
                                  
                
                                  Un serveur MCP (Model Context Protocol) donne de nouveaux outils à l'agent : GitHub, base de données,
                    fichiers, navigateur… Chaque appel te demande ton accord, sauf les outils que tu autorises d'office.
                    Chaque outil occupe aussi du contexte : n'active d'office que ceux qui servent souvent.
                                  
                
                                  
                
                                  
                
                                  
                    
                                  Ajouter un serveur
                                  
                    
                                  
                        
                        
                        
                        
                        
                        
                        
                    
                                  
                    
                                  npx demande Node.js (winget install OpenJS.NodeJS.LTS), uvx demande uv (winget install astral-sh.uv).
                        ${ARIA_PYTHON} lance le Python d'Aria. Les jetons et variables sont gardés en clair dans mcp.json, sur ton PC.
                                  
                    
                                  
                    
                                  
                        
                    
                                  
                
                                  
                
                                  
                    Modifier mcp.json directement (pour coller une config trouvée sur le web)
